# lunmont-site

Static source for the independent storefront at `lunmont.asia`.

Pure static HTML/CSS/JS — no build step, no server code. Deployed via Cloudflare Pages (output directory `/`), source kept in this GitHub repo.

## Contents
- `index.html` / `privacy.html` — page shells
- `themes/` — theme CSS + runtime (`site.js`, `theme-runtime.js`)
- `products.js` — SKU catalog (generated by the workstation site-studio panel; do not edit by hand)
- `assets/` — product images and business license
- `sitemap.xml` / `robots.txt` / `_headers` / `CNAME` / `.nojekyll` — hosting extras

## Update flow
Regenerate content from the workstation, commit here, push. Cloudflare Pages (Git integration) redeploys automatically.
